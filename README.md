# 🛒 Nilang Point of Sale (POS) App (নীলাং পিওএস অ্যাপ)

[![Language: Nilang](https://img.shields.io/badge/Language-Nilang%20%28%E0%A6%A8%E0%A7%80%E0%A6%B2%E0%A6%BE%E0%A6%82%29-00ADD8)](#)
[![Framework: Alap](https://img.shields.io/badge/Framework-Alap-005A9C)](#)

A full-featured Point of Sale (POS) Application re-written in **Nilang (নীলাং)** and built on top of the **Alap Framework**.

## 🚀 Features

- 📦 **Product & Category Management**: Dynamic stock tracking, low stock alerts, cost price history.
- 👥 **Customer & Supplier Relations**: Credit tracking, prepaid balance management, purchase orders.
- 💳 **POS Checkout & Sales**: Cash, UPI, and Mixed payment calculations with precise monetary precision.
- 📊 **Reports & Analytics**: Profit calculation, sales trends, stock overview, expense tracking.
- 🔐 **Role-Based Access Control**: Permissions management for Admins, Cashiers, and Managers.

## 🛠️ Running the Application

Ensure you have the Nilang compiler installed:

```bash
nil run src/main.nil
```

Or build with Nilang:

```bash
nil build
```
